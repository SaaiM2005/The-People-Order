# The People Order
> **Of people. For the people. By the people.**  
> A platform designed to build the future of work around humans again — connecting purpose-driven professionals, fractional leaders, and growth-oriented organisations.

## 🧩 Sections Included
1. **Header / Navbar**: Responsive navigation with brand pill buttons.
2. **Hero Section**: Cinematic photographic background with tagline badge and headline.
3. **Feature Cards**: 3 value proposition cards with accent border highlights (`01`, `02`, `03`).
4. **Founder Story & Metrics**: Samir's narrative, core values (*Intention*, *Clarity*, *Longevity*), and 4-stat metrics banner.
5. **Opportunities & For Organisations**: Searchable sector filters, job cards, and B2B partner grid.
6. **Champions & Fractional Opportunities**: 4 expert profile cards with booking CTAs and filtered project engagements.
7. **Community & Insights**: Featured essay, fortnightly newsletter form, LinkedIn/event cards, and resources library.
8. **Growth Support**: 2×2 service guidance grid with pastel number badges (`01`–`04`).
9. **Footer**: Deep dark (`#061D2B`) footer with brand wordmark, newsletter signup, and categorized navigation links.

## 🛠️ Quick Start
```bash
# 1. Clone & install dependencies
git clone https://github.com/SaaiM2005/The-People-Order.git
cd The-People-Order
npm install
# 2. Start local development server
npm run dev
# 3. Build for production
npm run build
# 4. Preview production build
npm run preview
```
